# dotfiles

macOS workstation: zsh, tmux, Ghostty, Neovim (Go/backend), git, yazi, lazygit.

## Install

```bash
git clone git@github.com:denilur/dotfiles.git ~/dotfiles
cd ~/dotfiles
make install    # brew bundle, links, ~/.zshrc hook, tmux + nvim plugins
make macos      # optional: key repeat, Finder, Dock defaults
```

Existing files replaced by links are moved to `~/.dotfiles-backup/<timestamp>/`.

## Update

```bash
make update     # git pull, brew bundle + upgrade, tmux plugins, vim.pack + treesitter
```

## Check

```bash
make check      # luacheck + stylua, shellcheck, headless nvim startup (also runs in CI)
make format     # stylua
```

## Layout

| Path | Linked to |
|---|---|
| `config/nvim` | `~/.config/nvim` — see [config/nvim/README.md](config/nvim/README.md) |
| `config/tmux/*` | `~/.config/tmux/` |
| `config/ghostty` | `~/.config/ghostty` |
| `config/yazi` | `~/.config/yazi` |
| `config/lazygit/config.yml` | `~/.config/lazygit/config.yml` |
| `config/worktrunk/config.toml` | `~/.config/worktrunk/config.toml` |
| `config/git/config`, `config/git/ignore` | `~/.config/git/` |
| `config/golangci.yml` | `~/.golangci.yml` (fallback for projects without own config) |
| `sh/{exports,aliases,helpers}.sh` | sourced from `~/.zshrc` |
| `sh/setup/` | install scripts used by `make` |
| `Brewfile` | `make brew` |

## Local, not in the repo

- `~/.gitconfig` — `[user]` only. Git reads it after `~/.config/git/config`, so it wins on conflicts.
- `~/.zshrc` — oh-my-zsh, work env (GOPROXY etc.). Dotfiles add only the
  `# >>> dotfiles >>>` block.

## Secrets

Kept in macOS Keychain, never in files:

- env tokens (`JIRA_PAT`, `GITLAB_PAT`, ...) — read in `~/.zshrc` via
  `security find-generic-password -a "$USER" -s NAME -w`.
  Add / rotate: `security add-generic-password -U -a "$USER" -s NAME -w`.
- git HTTPS tokens — `credential.helper osxkeychain` (git asks once, then remembers).
  Rotate: `printf "protocol=https\nhost=HOST\n\n" | git credential reject`, then the next
  `git fetch` asks for the new token.

## Shell helpers

- `tms` — fzf tmux session picker; type a new name to create one.
- `with-retry CMD...` — rerun until success (`RETRY_MAX_ATTEMPTS`, `RETRY_DELAY_SEC`).
- `pass-fzf` — pick a password-store entry and copy it.

## tmux

Prefix `C-a`. Splits: `|` / `-`. Panes: `C-h/j/k/l` (shared with Neovim via
vim-tmux-navigator), resize `prefix H/J/K/L`. `prefix a` — Claude Code
(`--continue`) in a right split, `prefix A` — new Claude session.

## Git worktrees

[Worktrunk](https://worktrunk.dev): `wt switch -c feature/x --base=@`, `wt switch pr:123`,
`wt list`, `wt merge`. New worktrees get ignored files (`.env` etc.) copied from the
main one; commit messages are generated by `claude -p --model haiku`.
